# Registro de Operações de Tratamento (ROPA)

> **MODELO INTERNO PARA PREENCHIMENTO E VALIDAÇÃO — NÃO VIGENTE**  
> Versão: 0.1 | Última atualização: 30 de julho de 2026

## 1. Instruções

Preencha uma linha para cada finalidade materialmente distinta. O registro deve identificar o papel do CutSync em cada operação e ser revisto quando houver novo dado, integração, recurso, fornecedor, país ou decisão automatizada. Não use o ROPA como repositório de dados pessoais de titulares.

## 3. Critérios de revisão

Reabrir o registro antes de habilitar dados sensíveis, biometria, dados de crianças/adolescentes, perfilamento, inteligência artificial, novo país, novo suboperador, integração de pagamento, decisão automatizada relevante ou exportação de dados em massa.
